# Illumina evidence import

In analysis **Overview & logs → Delivery manifest & yield → Illumina demultiplexing evidence**, import existing CSV reports. This is read-only evidence inspection; it does not perform basecalling or demultiplexing and never opens a FASTQ path mentioned inside a report.

Supported allowlisted filenames are `SampleSheet.csv`, `Demultiplex_Stats.csv`, `Quality_Metrics.csv`, `Index_Hopping_Counts.csv` and `fastq_list.csv`. Uploads retain exact original bytes (including BOM/line endings), SHA-256, import actor/time and immutable registered download artifacts. Limits: five documents, 2 MiB each, 4 MiB total and 10,000 CSV rows. Unsupported headers or malformed CSV fail explicitly and retain previous successful evidence. Previous imports remain in manifest history. Unknown/missing evidence is not evaluated, never silently accepted.

The explicit schemas are covered by unmodified BCL Convert **3.6.3** and **3.9.3** reports from the MultiQC test-data repository. The adapter handles the older eight-column Demultiplex_Stats and newer eleven-column schema, the verified Quality/Index-Hopping/FASTQ-list headers, and SampleSheet v1 `[Data]` / v2 `[BCLConvert_Data]`. Other report layouts must be verified before adding another adapter.

The CSVs do **not** report a reliable BCL Convert software version. Schema family is distinct from measured version. Optional version/run identifiers are explicitly user-declared; the SampleSheet `[Demultiplexing] runID` is retained separately when present. A conflicting declared run ID requires attention.

Expected sample IDs, lanes and complete index/index2 combinations are reconciled against actual demultiplex rows. Nucleotide case is ignored for index matching; sequences are not reverse-complemented. Missing, unexpected, duplicate or non-unique assignments require review. No sample swap, contamination or index misassignment is inferred. SampleSheet settings are retained as upstream metadata, not executed. The official [Illumina sample-sheet specification](https://support-docs.illumina.com/SW/BCL_Convert/Content/SW/BCLConvert/SampleSheets_swBCL.htm) defines these sections and index fields.

Illumina reports `# Reads` as passing-filter demultiplexing observations. QualiDock preserves that label and does **not** equate it to the sum of R1 + R2 FASTQ record counts. Lane totals sum unique imported lane/sample/index observations; the displayed Undetermined percentage has an explicit denominator of those imported rows. This does not independently verify full run coverage. No Undetermined row means unavailable, not zero. See [Illumina's metrics documentation](https://support-docs.illumina.com/SW/BCL_Convert/Content/SW/BCLConvert/BCLConvert_MetricsOutput.htm).

Raw table cells preserve original precision. For example, the reported `% Reads` lexical value `0.0029` remains `0.0029`; the separately labeled share of imported rows is calculated directly from the original integer counts. Q30/base yields remain separate per-read reported observations. Blank hopping measurements remain **Not reported**; expected-index counts are never relabeled as hopped-read counts. Sample allocation is visible per lane without a universal unevenness or contamination threshold.

Explicit `fastq_list.csv` mappings use unique filename + lane + read identity against selected source files. Ambiguous or absent matches are shown. Sample display names are not used to manufacture a biological relationship, and the original upstream path strings are never filesystem input instructions. Original CSV downloads can contain upstream identifiers/paths; review before sharing. Delivery manifest exports contain only a compact upstream provenance/denominator summary, not arbitrary raw report contents.

The authenticated `POST /api/runs/{id}/demultiplex` endpoint takes `{documents:[{name,content_base64}],declared_tool_version?,declared_run_id?}`. Read normalized evidence through `GET /api/runs/{id}/delivery`; originals use the existing registered attachment endpoint. Optional per-run fields preserve historical compatibility without a database migration or scientific-output modification.
